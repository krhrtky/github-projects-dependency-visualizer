同期は全ページを走査し、可視 4 Issue と画面外の 1 Issue を含む 5 Issue を対象にする統合テストを行いました。プレビューが書き込みを行わないこと、3 つの実カスタムフィールドの作成、所有権の段階保存、未所有の同名フィールドの拒否、差分だけの更新、既存の表示列と標準親子フィールドの維持を確認しました。同期中に保存された表示列も再読込して維持します。1,000 Issue 超過、取得失敗行の保持、View 設定だけの失敗、Roadmap の表示設定を変更しないことも検証しています。

合成データの Table・Roadmap・Board で、既存の OR 条件を保った標準フィルターの追加、行の仮想化・再利用、SPA 遷移、UI の破棄とフォーカスを検証しました。操作欄の挿入後に座標を計測することで、View 切り替えの初回描画にも対応します。座標・ラベル重なり・スクロール・SPA を含む Project View の 3 シナリオは、修正後に 5 回繰り返し、15 回すべて成功しました。

## 表示ラベルの確認（2026-10-19）

線の `#1 → #2` と一覧の `#2 は #1 に依存` が同じ依存を示すこと、Repository と所有者が異なる同番号の Issue を区別することを確認しました。矢印ラベル下段と一覧には `深さ 0 → 1` のように両端の依存の深さを表示します。途中の段を飛ぶ `深さ 0 → 2`、循環時の `深さ 未算出` も検証しています。「依存の一覧」は初期表示で開き、深さ・分岐・合流の指標と定義は折りたたみから確認できます。表示変更を適用した既存構成の検証用コピーで、型検査・本番ビルド、128 件の単体・DOM テストと 9 件の Chromium 拡張統合テストが成功しました。作業フォルダの統合後の構成でも、型検査・本番ビルドと表示関連の Chromium 統合テスト 5 件が成功しています。

合成データの Board（Light / Dark）・Table・Roadmap の画像で表示を確認しました。Board の 5 本、Table・Roadmap の各 4 本すべてに Issue と深さのラベルがあり、実 DOM 矩形でカード本文とラベル同士に重なりがないことを確認しています。720 × 512 の表示領域でパネルが画面内に収まり、長い識別子が横にはみ出さず折り返すこと、Tab / Enter による選択と強調解除、解除後のフォーカス復帰を Chromium で検証しました。コントロールへのフォーカスでは依存を再取得せず、ウィンドウへのフォーカス時には再取得することも回帰テストで確認しています。

## 新しい描画・解析の確認

- 同じ列に並ぶ4カードと別列の1カード、合計5辺で、同列の経路が別レーン・別ポートになることを確認。
- A→B→C→D と A→C、A→E を含むグラフで、最長3段・分岐1・合流1を確認。「最長経路のみ」は A→B→C→D の3辺を表示。
- 同長の最長経路が複数ある場合は、すべての最長経路の辺・ノードを検出。
- カード選択による上流・下流の強調、影響先の重複除去、番号による個別関係の強調を確認。
- D→A を追加した循環で、深さ・最長経路を未算出にし、循環内の5辺だけを赤い破線にすることを確認。循環から外へ出る辺は通常表示。
- 関係選択時のキーボードフォーカス維持、ページに削除された Overlay の復元、取得中・不完全な解析の注意表示を確認。
- 200カード・1,000辺で、経路の入力順不変・有限座標・共有元カードの接続ポートの分離を検証。

経路計算単体のローカル測定では、200カード・1,000辺を10列に配置した場合は約5ms、全カードを同じ列に配置した場合は約10msでした。これは SVG の DOM 生成・レイアウトを含まない参考値であり、実 GitHub 上の描画時間を保証しません。解析は関係が変わったときだけ再計算し、経路は座標が変わったときだけ再計算します。

## 制限と実環境での確認範囲

- 解析対象は現在のビューポートと列のスクロール領域に実在する Issue カード間の、取得できた関係だけです。画面外を含む Project 全体の最長経路は算出しません。
- 最長経路は辺数による依存の深さです。工数・期間・休日・担当者の容量は含みません。循環が1つでもあればグラフ全体の深さ・最長経路を未算出にします。
- 同列の線は中間カードと隣列を考慮して左右へ迂回します。十分なガターがない場合はレーンを圧縮し、警告を表示します。全カードを対象とした完全な障害物回避や、列をまたぐ線の交差の最小化は行いません。
- 上限は可視範囲のユニークな200 Issueです。取得中は暫定値、部分失敗や上限超過時は不完全な値です。
- GitHub の Board/Table の匿名化した実 DOM 構造を Fixture に含みます。GitHub の DOM は安定した公開 API ではなく、将来の変更や他の Project の構造は保証しません。
- 0.2.0 の追加機能は模擬 Board / API で検証しました。実 GitHub 上での新しい線の見え方、ドラッグ中の追従、大量カード時の応答性は利用環境で確認してください。
- Chrome Web Store の公開・自動更新は提供しません。配布 ZIP を展開し、Chrome のデベロッパーモードから読み込みます。
